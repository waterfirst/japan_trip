# japan_trip

2026 일본 알프스 여행 가이드북입니다. 탭 기반 단일 페이지(`index.html`)에서 일정·지도·교통·여행 일본어·미디어와 함께 날짜별 여행 에세이를 모두 확인할 수 있습니다.

## Pages

- 가이드북(탭 통합): `index.html`
  - 🏠 홈 / 🗺 전체 지도 / Day 1~4 / 교통·맛집·팁 / 체크리스트 / 🇯🇵 여행 일본어 / 🎬 미디어 / 📖 여행 에세이
- 여행 에세이(단독 페이지): `essay.html`
- 사진 자산: `assets/trip/`

## 운영 방식

- 메인 페이지는 탭으로 일정/동선 가이드와 여행 에세이를 함께 제공
- 여행 에세이 탭은 날짜별 사진과 짧은 소감 기록
- 여행 중 사진이 들어오면 `assets/trip/` 날짜 폴더에 추가하고 에세이 탭을 갱신
